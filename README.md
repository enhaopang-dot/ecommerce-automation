## 这是什么

一份**电商平台取数的方法论工具包**，给做电商数据分析、AI 投放、店铺运营的人用。它回答四个问题：

1. 这个平台的开放平台在哪、怎么申请
2. 开放 API 到底能拿到哪些字段，哪些拿不到
3. 拿不到的部分，浏览器自动化怎么补
4. 每一类数据要经过哪几个页面、导出什么格式

不是代码库，是**踩过坑之后写下来的路线图**。

## 为什么需要它

电商平台的数据获取有三道坎：

- **开放平台门槛不透明**：有的要企业认证，有的要类目在池，有的干脆不开放
- **文档和实际不一致**：文档写「支持」，实际返回空
- **能拿到的字段比想象中少**：直播明细、完播率这类核心数据常常只能手动导出

这份文档把每个平台的真实状态标清楚：✅ 已打通 / ◐ 申请中 / ○ 未接入 / ✗ 不开放。

## 内容

```
├── SKILL.md                            总台说明与平台索引
├── references/
│   ├── platforms.md                    各平台取数能力对照（入口/账号类型/数据范围/限制）
│   └── browser-extraction-playbook.md  浏览器取数实操：页面路径、导出字段、坑位
└── registry/
    └── platforms.json                  平台注册表（结构化，可被程序读取）
```

## 用法

在支持 skill 的 Agent 里直接放进 skills 目录；也可以当纯文档翻。

典型问法：
- 「千川的数据怎么取」
- 「抖店能不能用 API 拿订单」
- 「这个平台的开放平台在哪」

## 重要提醒

**取数结论有时效。** 平台会改规则、改类目、改权限。本文档所有「不支持 / 只能这样」的说法都带核实日期，用之前先看一眼是不是几个月前的结论。
